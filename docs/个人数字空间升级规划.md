## A. 现有项目架构分析

### A1. 后端 **[确认]**
- FastAPI 模块化单体（约 1,400 行 Python）：入口 `app/main.py`（119 行），6 个业务路由模块（auth/blog/tags/workspace/music/cloud），core 层 6 个基础组件（config/database/security/sanitize/audit/ratelimit），3 个运维脚本（init_admin/backup/migrate_v2）。
- 数据层：SQLite 三库（blog.db 主库 + workspace.db/music.db 以 `ATTACH` 挂载），WAL 模式 + 外键约束，thread-local 连接。启动时 `migrate_v2.py` 幂等建表（v2.1 修复后含 visibility 自愈）。
- 认证：JWT 双令牌（access 15min / refresh 7d，PyJWT HS256）+ bcrypt（锁 4.0.1）+ `require_admin` 依赖注入（服务端验证）。登录失败限流 15min/5 次、refresh 限流 60s/30 次。
- 安全头：CSP（script-src 'self'，style 允许内联 + Google Fonts）、nosniff、DENY、HSTS 开关。CORS 白名单。
- 审计：`logs/audit.log` 文本日志（时间/操作/用户/IP/结果），登录、上传、删除、可见性切换均有埋点。
- 部署：Docker Compose 双容器（Nginx alpine 静态+反代，app 不暴露宿主机端口），配置走 `.env`。**[确认]** compose 配置存在但**从未在服务器实测**（本地沙箱无 Docker）。

### A2. 前端 **[确认]**
- 全部原生 HTML/CSS/JS（public/ 目录约 1,760 行）：8 个页面（首页/文章列表/文章详情模板/留言/关于/订阅/音乐/admin），3 个共享 JS（site.js 227 行：设置注入/留言/订阅/搜索；hands.js 232 行：首页 canvas 点阵动画；music.js 191 行：播放器）。
- **admin 后台已是"左侧栏 + hash 路由"结构**（v2.1 重构）：11 个面板（工作台/网盘/音乐/文章/分类/标签/留言/订阅/设置/审计/管理员），其中标签、审计、管理员为占位说明页。
- CSS：site.css 仅 233 行，**无 design token 体系**——颜色全部硬编码（#111/#f7f7f5/#e8e8e5 等），无暗色模式，无图标系统（每页内联 SVG 手抄）。视觉基线是"极简黑白编辑部风"，与 Liquid Glass 目标差距较大。
- 响应式：760px 断点单一，无平板中间档。

### 已实现（代码+测试确认）

- 音乐：上传（五层校验）/Range 流媒体/可见性开关/公共播放页（循环播放）。

- 工作台：笔记/待办/书签全 CRUD（有后端有后台 UI）。
- 后台：左侧栏 11 面板、JWT 登录、统计卡片、审计日志（写）。

### 部分实现
- 标签管理：后端 API 完整（tags/router.py 117 行），后台只有占位页——**可直接补 UI，零后端工作**。

## E. Liquid Glass 设计规范（Design Token 草案）

落地方式：site.css 头部新建 `:root` token 层 + `.glass` 工具类，**存量页面渐进迁移**（先变量后组件）。

```css
:root {
  /* 表面与玻璃 */
  --surface: #f5f5f7;            /* 页面底（iOS 灰） */
  --glass-bg: rgba(255,255,255,.62);   /* 玻璃面板底 */
  --glass-bg-strong: rgba(255,255,255,.82);
  --glass-blur: saturate(180%) blur(24px);  /* 面板 */ 
  --glass-blur-thin: saturate(160%) blur(14px); /* 顶栏/悬浮层 */
  --hairline: rgba(0,0,0,.08);         /* 1px 发丝边 */
  --highlight: rgba(255,255,255,.65);  /* 顶部内高光 inset */
  /* 文字（对比度 ≥ AA） */
  --ink: #1d1d1f; --ink-2: #55555a; --ink-3: #86868b;
  /* 主题色：单一克制的强调色，拒绝霓虹 */
  --accent: #0a84ff; --accent-ink: #fff;
  /* 几何 */
  --r-s: 10px; --r-m: 16px; --r-l: 22px; --r-pill: 999px;
  --space-1: 4px … --space-8: 64px;   /* 4px 网格 */
  /* 阴影：柔和双层，不用黑色大投影 */
  --shadow-1: 0 1px 2px rgba(0,0,0,.05), 0 8px 24px rgba(0,0,0,.06);
  --shadow-2: 0 2px 6px rgba(0,0,0,.06), 0 20px 48px rgba(0,0,0,.10);
  /* 动效：统一时长与缓动 */
  --t-fast: 150ms; --t-base: 250ms; --t-slow: 400ms;
  --ease: cubic-bezier(.32,.72,0,1);   /* iOS 手感 */
}
.glass { background:var(--glass-bg); backdrop-filter:var(--glass-blur);
  border:1px solid var(--hairline); border-radius:var(--r-m);
  box-shadow:var(--shadow-1), inset 0 1px 0 var(--highlight); }
```

**纪律**：① `backdrop-filter` 只用于顶栏/侧栏/弹层/卡片四类，正文区用实底（性能）；② 动态背景仅在首页 Hero（复用 hands.js 优化版：设备像素比上限 2、帧率 30fps、`visibilitychange` 暂停）；③ 动画只做 opacity/transform（合成层）；④ 暗色模式 Phase 0 只做 token 预留（`@media prefers-color-scheme` 换值），组件后续跟进；⑤ 图标：单文件 `icons.svg` sprite + `<svg><use>`，24 网格/1.8px 线宽/圆头，一次定义全站复用。

### 新增 API（全部 `require_admin` 服务端校验）
- `/api/admin/projects` CRUD + `/api/admin/projects/{id}/logs`
- `/api/public/projects`（公开只读，visibility 过滤——沿用音乐 visibility 模式）

## I. 各阶段验收标准与测试清单（通用底线 + 阶段专项）

**通用底线（每阶段必过）**：① `v2_functional_test.py` 全绿（含既有 77 项反例：401/429/416/400）；② 新接口全部含未登录 401 / 非法参数 422 反例；③ 迁移幂等（连续跑两次结果一致）+ 备份存在；④ CSP 不放宽（AI SSE 用 connect-src 'self' 即可）；⑤ 手机 375px 与桌面 1440px 双档人工过一遍；⑥ `node --check` 所有改动 JS。

**阶段专项示例**：P0——所有玻璃面板在纯色背景下文字对比度 ≥ 4.5:1（取色器实测）；`prefers-reduced-motion` 下动画关闭；CPU 空载时动画帧率 ≤ 30fps 稳定。P3——番茄钟计时不因刷新丢失（localStorage + 服务端落库双写）。P6——AI 回复中 `<script>` 经 sanitize 后不可执行；密钥不出现在任何响应体/前端代码。
