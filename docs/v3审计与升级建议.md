## 一、阻断级缺陷（不修则 v3 无法上线）

### A1 SPA 深链在后端全部 404，两套前端无整合路径
- 触发条件：任何直接访问 `/articles`、`/post/x`、`/projects`、`/yy-AviuuP3r` 的请求（非从首页点击进来的用户、刷新、分享链接、搜索引擎）。
- 证据：`app/main.py:127` 挂载 `StaticFiles(directory="public", html=True)`；实测 `:3002` 下上述 4 条路径全部 404，`/` 返回的是**原版 HTML 首页**，不是 Vue 应用。`frontend/dist` 不存在（从未构建）。
- 影响：v3 目前是只能靠 Vite dev server 访问的并行实现，无法替换 v2；用户书签/回退全部失效。
- 修复：`vite build` → 后端新增 dist 挂载 + history fallback（未命中静态文件时回 `index.html`）；旧 `.html` 与 `/post-x.html`、`/projects/{slug}.html` 加 301 到新路由；后台页 `/yy-AviuuP3r` 保持隐匿路径不变。

### A2 后台静默续期完全失效，15 分钟后必然掉线
- 触发条件：登录后 access 令牌过期（`ACCESS_TOKEN_MINUTES=15`）后的任意一次后台操作。
- 证据：`frontend/src/admin/api.js:31-38` 的 `withRetry` 用 **GET 原始业务路径 + Bearer 刷新令牌** 去续期；后端 `app/core/security.py:59` 明确 `payload.get("typ") != expected_type → 401`，刷新令牌 typ 是 `refresh`，因此该请求恒 401 → `clearTokens()` → 提示"登录已过期"。真正的续期端点 `POST /api/auth/refresh`（`app/modules/auth/router.py:55-60`，需 JSON body `refresh_token`）在 v3 里从未被调用。
- 对照：原版 `public/admin.js:49-59` 实现正确，且保存了后端轮换返回的新 refresh_token；v3 即使调对端点，`setTokens(d.access_token, refresh)` 也会丢掉轮换。
- 修复：`api.js` 改为 `POST /api/auth/refresh` + body + 写回两个令牌；与原版共用 `admin-access/admin-refresh` 键（已确认键名一致 ✓）。

### A3 引用了不存在的静态资源，v3 图标实际是坏的
- 触发条件：任何 v3 页面加载。
- 证据：`frontend/index.html:5` 引用 `/y-mark.svg`，但 `frontend/public/` 只有 `favicon.svg`、`icons.svg`、`kindred-hands.webp`；实测 Vite 对 `/y-mark.svg` 返回 `Content-Type: text/html`（SPA 回退），浏览器无法按图片解析。
- 修复：把 `public/y-mark.svg` 复制进 `frontend/public/`（或改引用名）；同时补 `<meta name="description">`、OG 标签、`<link rel="alternate" type="application/rss+xml" href="/rss.xml">`。

## 五、工程一致性

1. **两套请求层并存**：`admin/api.js` 有令牌刷新与 `{ok,status,data}` 约定，9 个前台页各自裸写 `fetch` + `try/catch`，错误文案、loading 状态、数组兼容（`Array.isArray(d) ? d : d.items`）重复实现 6 次。后端返回裸数组是既定契约（记忆里也记过这个坑），应收敛成 `src/api/client.js` + `useFetch` 组合式函数。
2. **常量重复且不完整**：项目状态映射在 `ProjectsView.vue:28`（4 项齐全）与 `ProjectView.vue:35`（3 项，`idea/archived` 直接露出英文）各写一份。
3. **注释与实现不符**：`glass/engine.js:12` 声称"边缘质感交给 CSS rim light（见 glass.css 的 `.lg-rim`）"，实测 `glass.css` 无 `.lg-rim` 类（实际来自 `.lg-surface` 的 inset box-shadow）。
4. **无任何前端自动化测试**：无 Vitest、无 Playwright 用例、无 ESLint/Prettier；`vite.config.js` 无构建产物与后端的联调配置。当前"回归全绿"只覆盖后端。
5. **样式双轨**：`frontend/src/styles/*` 与 `public/site.css`（原版 token 层）并行，v3 token 文件定义 50 个变量、已漏 `--focus-ring`，迁移期会持续漂移。
